# Re:Ultimate branding

The Crest brand. The docs site's DESIGN.md (RE-Ultimate/docs) describes how to use it.

| File | What it is |
| --- | --- |
| `wordmark.png`, `wordmark-large.png` | Primary logo: "RE:ULTIMATE" in Pixelify Sans 700 with the three-step oak extrusion and a torch-gold colon. Transparent background, for dark grounds. |
| `icon.svg`, `icon-512.png` | The "gold colon" icon on a 16 x 16 pixel grid. Scale by whole pixels only. |
| `social-card.png` | 1200 x 630 link preview card. |
| `loading.png` | Earlier loading image, kept until a Crest version replaces it. |

Colors: background `#1b1713`, text `#f3e9d8`, torch gold `#f2b25c`, extrusion `#c79a5b` / `#8a5f30` / `#4a3016`.
